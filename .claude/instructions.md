# Project: Chora
- Goal: An experimental agent runtime treating agents as managed processes within a shared execution field.
- Metaphor: Chora is the primordial container — agents take form and life within it.
- Language: Rust (main), Python (experiments).
- Async: Tokio.
- Storage: SQLite for agent context/memory.
- Architecture:
  - `runtime` crate: Agent abstraction, lifecycle, process table, execution field.
  - `memory` crate: Context management, memory tiers (working/episodic/semantic).
- Conventions:
  - All Rust public APIs must be documented.
  - Every non-trivial concurrency decision must include a reasoning comment.
  - Python experiments are throwaway but must have a README reproducing the insight.
- Do not introduce frameworks before clarifying the core abstraction first.
